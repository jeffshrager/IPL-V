### 3. Getting the deck to run (fixes in order of discovery)
1. **Restart header.** The type-5 card `4 2` ("reload from tape 2", P=4) was taken as a
   start card. It is now a no-op, since memory is already in place.
2. **Card input columns.** LT's M89 counts columns from N1 = 1, so it assumes 1W25 = 1
   after J180. J180 set 0, which shifted every name one column right. J180 now sets 1.
3. **`P` vs `P0`.** J186 inputs `P0`, but the deck defines `P`. Lone regional characters
   are now read as `X0`.
4. **PQ 01 in routines.** `01W5` (execute the routine named in W5) was read as an integer
   data term. The card reader now knows the load mode.
5. **J68 stale link.** This produced a stray `0` in M62's theorem list, and *2.03 crashed
   in M12/J81. The cell J68 removes is now cleared, and H5+ is set.
6. **Print columns.** Every line-I/O J is now 1-based (J154, J156, J157, J160 = 1W21+(0),
   J182). Before the fix, `*1.01` printed as `1.01` and `DEF.` as `EF.`.
7. **Subproblem numbers printed as `0.`.** J136 was overwriting a data term's Q=1.
8. **Blank /16 external name.** An all-blank PQ-21 term is now 5 columns, not 1. This put
   the `, SUBLEVEL REPLACEMENT` comma column right.
9. **`K31 YES`.** It must equal `Y` for rejected problems to print. Non-digits after the
   region character are now dropped.
10. J156 prints an internal name `9-nnn` as `nnn`.

Jeff warned that dmoews's transcription might have off-by-one errors in the printing.
Fixes 6 and 8 were therefore justified from the manual and from lines that name real
theorems (which match exactly), not from blank-name lines alone.

### 4. Result
- 24/24 theorems give the same result as 1963. 23/24 have identical subproblem and
  substitution counts, and their traces and proofs match line for line.
- Effort is about 0.66× the 1963 figure (cycle accounting).
- *2.15 runs out of effort in both, but later in ours (48 subproblems vs 31). The first
  31 match.
- Remaining text differences:
  - our wider internal numbers cut `REJECTED PROBLEM` at column 80;
  - transcription noise: `DFF.` for `DEF.`, two missing commas, blank lines.
- Ackermann tests still pass (61 and 125).
