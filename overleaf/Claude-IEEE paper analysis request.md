This is Jeff Shrager's next "reanimation" project after ELIZA — a **Common Lisp emulator/interpreter for IPL-V** (Information Processing Language, version V), with the goal of getting the **Logic Theorist** running again. This is directly connected to the ELIZA paper we just discussed; Shrager is one of the same researchers.

**IPL-V** was the programming language created by Allen Newell, Cliff Shaw, and Herbert Simon at RAND/Carnegie around 1956. It was an assembly-language-style language for manipulating lists, and it included features like dynamic memory allocation, recursion, higher-order functions, and cooperative multitasking — innovations that were later generalized and incorporated into Lisp. IPL-V was the language used to write the **Logic Theorist**, the first program deliberately engineered to perform automated reasoning, which proved 38 of the first 52 theorems in chapter 2 of Whitehead and Russell's Principia Mathematica.

The repo contains several key pieces:

- **`iplv.lisp`** — the entire IPL-V emulator in a single Common Lisp file
- **`LT/`** — the Logic Theorist code transcribed into IPL-V
- **`EPAM/`** — code for EPAM (Feigenbaum's early learning program, also written in IPL-V)
- **`claudecode/`** — interestingly, a directory suggesting Claude Code was used in development
- **`misccode/`** — miscellaneous supporting code

From the Hacker News thread, Shrager noted that unlike ELIZA (which was in a Lisp-like language easily mapped to modern Lisp), IPL-V can't be straightforwardly translated to Lisp despite being its direct predecessor. He also mentioned that he and Ed Feigenbaum are probably the only living people who know IPL-V, since Lisp supplanted it so quickly.

So this is essentially a companion effort to the ELIZA reanimation — bringing back another foundational AI program on its original language platform, this time reaching even further back to what many consider the very first AI program (1956, predating even the coining of the term "artificial intelligence" at the Dartmouth conference).
