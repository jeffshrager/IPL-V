## Work Done

### 1. `extract-proof.sh`

New script at repo root. Extracts a single proof's DOT block from a `.dotstar`
file and renders it to PDF.

**Arguments:**
- `dotstar` — path to `.dotstar` file, or `.` for the most-recent file in `ltresults/`
- `theorem` — theorem id in any form: `425`, `4.25`, `*4.25`, `*425`, `201`, etc.
- `output` — PDF output path or directory (default: `.`)

**Normalization:** strips a leading `*`, then if no dot is present inserts one
before the last two digits (`425` → `4.25`, `201` → `2.01`). Searches for the
dotstar separator line `// Problem *N.NN`.

**Error handling:** if the theorem isn't found, lists all available theorem labels
from the dotstar so the user knows what to ask for.

**Extraction:** awk walks the dotstar, sets a flag on the `// Problem *N.NN`
separator line, starts capturing at `^digraph`, stops and exits at `^}$`.
Writes the block to `/tmp/lt-proof-NNN.dot` then runs `dot -Tpdf`.

### 2. User quiet-mode edits to `lt.lisp`

User quoted out several noisy `format t` and loop calls to reduce run-time
verbosity.  Changes (all by prepending a `'` to make the form self-quoting,
i.e. a no-op):

| Location | What was silenced |
|----------|-------------------|
| `proof-graph!` | `"Proof graph: N major-method invocations"` header print |
| `proof-graph!` | The indented text-dump loop (`loop for node in (rest all-nodes)`) |
| `proof-graph!` | `"Wrote N nodes to ..."` and `"Render: dot ..."` footer prints |
| `emit-proof-graph!` | The `// ====` separator block written to `*lt-dotstar-stream*` |
| `*trace-exprs*` M001R000 entry | `"===== Proof of ... started at cycle ... ====="` print |

> **Note:** The dotstar separator being quoted out means the `.dotstar` file now
> contains raw concatenated `digraph` blocks without `// Problem *N.NN` headers.
> `extract-proof.sh` relies on those headers to locate theorems.  If the dotstar
> separator stays quoted, `extract-proof.sh` will not be able to find proofs by
> name.  The separator should be restored (un-quote the `when *lt-dotstar-stream*`
> block in `emit-proof-graph!`) if `extract-proof.sh` is to be used.
