## Root Cause: J10 DL One-Hop Traversal Bug

The DL (description list) structure built by `J11-helper-add-to-dlist` is flat:
```
dlist-head → att1 → val1 → att2 → val2 → "0"
```

J10's no-match branch was advancing **one hop** (att-cell → its link = val-cell),
treating the val-cell as the next att-cell. When a val-cell's `symb` happened to
equal the search target ("A0" stored as a substitution value), J10 falsely matched —
then tried `(cell (cell-link val-cell))` = `(cell "0")` = NIL → crash at `(cell-symb NIL)`.

The comment `"** Check me !!"` in `defj J10` had flagged this from the start.

## Fix

In the no-match branch of J10's loop, skip **two hops** (att→val→next-att):

```lisp
;; OLD (wrong) — one hop, treating val-cell as next att-cell:
(let* ((next-att-link (cell-link dl-attribute-cell)))
  (if (zero? next-att-link)
      (progn (H5-) (return nil))
      (setf dl-attribute-cell (cell (cell-link dl-attribute-cell)))))

;; NEW (correct) — two hops, properly skipping val-cell:
(let* ((val-cell-name (cell-link dl-attribute-cell)))
  (when (zero? val-cell-name)
    (H5-) (return nil))
  (let* ((val-cell (cell val-cell-name)))
    (when (null val-cell)
      (H5-) (return nil))
    (let* ((next-att-name (cell-link val-cell)))
      (if (zero? next-att-name)
          (progn (H5-) (return nil))
          (setf dl-attribute-cell (cell next-att-name))))))
```

Location: `defj J10` (~line 954-968 in iplv.lisp).

## Lessons
- **Read the "Check me" comments** — they mark unverified code that was suspected bad
- **DL is flat att/val pairs** — traversal must always skip pairs, not single cells
- **Edit tool for Lisp paren fixes** — never use Python scripts on Lisp files; if Edit
  introduces paren imbalance, count depth manually and fix with another Edit
- **git commit before risky edits** — the committed J74 fix was recoverable via checkout
